# E-Commerce Storefront Flows & Screen Architecture

This skill provides production-grade templates and architecture for complete e-commerce user journeys from discovery to post-purchase.

---

## 1. Core Storefront Flows

1.  **Product Discovery (PLP / Category Grids)**: Faceted filter sidebar, sorting selector, quick-add, quick-view modal.
2.  **Product Detail Page (PDP)**: Interactive media gallery, sticky Buy Box, accordion details, customer reviews breakdown.
3.  **Cart Drawer & Quick Checkout**: Slide-out drawer with real-time subtotal, free shipping meter, one-click Apple Pay/Google Pay.
4.  **Multi-Step / One-Page Checkout**: Frictionless inputs, live address autocomplete, inline credit card validation.
5.  **Post-Purchase & Customer Portal**: Order confirmation, live tracking timeline, customer account order history.
